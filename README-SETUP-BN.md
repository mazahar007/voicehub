# ভয়েস স্টুডিও — Voice SaaS V1 — সেটআপ গাইড (বাংলা)

> **এই বিল্ডটি এখনো LIVE নয়।** কোড তৈরি, `tsc` ও `next build` যাচাই করা
> হয়েছে — কিন্তু GitHub-এ পুশ করা হয়নি, Vercel-এ ডিপ্লয় করা হয়নি, আর
> কোনো API key চাওয়া বা সেট করা হয়নি। নিচের ধাপগুলো শেষ হলে তবেই লাইভ হবে।

## V1-এ যা আছে

- **ল্যান্ডিং পেজ** (`/`) — বাংলা-প্রথম, সাথে ইংরেজি ল্যান্ডিং (`/en`)
- **স্টুডিও** (`/app`) — টেক্সট বক্স, ভয়েস বাছাই, মডেল বাছাই,
  stability/similarity স্লাইডার, ক্যারেক্টার কাউন্টার, Generate → অডিও
  প্লেয়ার + MP3 ডাউনলোড, হিস্ট্রি (ব্রাউজারে)
- **প্রাইসিং** (`/pricing`) — সব দাম DRAFT, মালিকের অনুমোদন ছাড়া বিক্রি নয়
- **অ্যাডমিন** (`/login` → `/admin`) — ডেমো পাসকোড দিয়ে ব্যবহারের হিসাব
- **API রুট** — `/api/health`, `/api/voices`, `/api/tts`, `/api/stats`
- **ক্রেডিট সিস্টেম** — Supabase স্কিমা (`supabase/schema.sql`) + ইন-মেমোরি
  DEMO লেজার (redeploy-এ রিসেট হয়)

## V1-এ যা নেই (সৎভাবে)

- ভয়েস ক্লোনিং নেই। ক্লোনিং শুধু পেইড প্ল্যানে আসবে, এবং শুধু যার ভয়েস
  তার লিখিত অনুমতি থাকলে। ফ্রি টিয়ারে ক্লোনিং দেওয়া হয় না।
- পেমেন্ট / চেকআউট নেই (bKash / Stripe পরের ধাপে)।
- ইউজার অ্যাকাউন্ট / লগইন সিস্টেম নেই — শুধু ডেমো অ্যাডমিন পাসকোড আছে।
- API key ছাড়া কোনো অডিও তৈরি হয় না — নকল অডিও দেওয়া হয় না।

## ধাপ ১ — ElevenLabs ফ্রি অ্যাকাউন্ট + API key

1. elevenlabs.io-তে যান, **Sign up** করুন (ফ্রি টিয়ারে কার্ড লাগে না)।
2. Profile → **API Keys** → **Create API Key** → নাম দিন → key কপি করুন।
3. ফ্রি টিয়ার: মাসে ১০,০০০ ক্রেডিট, শুধু অ-বাণিজ্যিক ব্যবহার, ক্লোনিং নেই।
   বাণিজ্যিক ব্যবহার ও ক্লোনিং পেইড Starter প্ল্যান থেকে শুরু।
4. key কাউকে মেসেজে পাঠাবেন না, GitHub-এ কমিট করবেন না — শুধু Vercel-এর
   env var-এ বসাবেন (ধাপ ৪)।

## ধাপ ২ — Supabase প্রজেক্ট + স্কিমা (V2-র প্রস্তুতি)

1. supabase.com-এ নতুন প্রজেক্ট বানান।
2. Dashboard → **SQL Editor** → New query → `supabase/schema.sql`-এর পুরো
   ফাইল পেস্ট করে **Run** করুন।
3. Project Settings → API থেকে `URL` ও `service_role` key নোট করুন।
4. মনে রাখবেন: V1 এখনো Supabase পড়ে না — এটি V2 ওয়্যারিংয়ের প্রস্তুতি।

## ধাপ ৩ — GitHub রিপো (আপনাকে বানাতে হবে)

1. GitHub-এ নতুন রিপো বানান (যেমন `voice-saas`)।
2. এই প্রজেক্টের সব ফাইল (node_modules ও .next ছাড়া) আপলোড করুন।
3. `.env` ফাইল কখনো আপলোড করবেন না — শুধু `.env.example` যাবে।

## ধাপ ৪ — Vercel ডিপ্লয় + env var

1. Vercel Dashboard → **Add New → Project** → GitHub রিপো Import করুন।
2. **Environment Variables**-এ বসান (Production-এর জন্য Enabled আছে কি না
   যাচাই করুন):
   - `ELEVENLABS_API_KEY` = ধাপ ১-এর key
   - `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`
     = ধাপ ২-এর মান (V2-র জন্য; V1-এ না বসালেও অ্যাপ চলবে, ডেমো মোডে)
   - `ADMIN_PASSCODE` = নিজের পাসকোড (না বসালে ডেমো 1234)
3. **Deploy** করুন, তারপর **Redeploy** করে নিশ্চিত করুন env var
   Production-এ কার্যকর হয়েছে।

## ধাপ ৫ — যাচাই (লাইভ বলার আগে)

1. `/api/health` খুলুন — `elevenlabs_configured: true` দেখতে হবে।
   `false` থাকলে env var Production-এ Enabled হয়নি বা redeploy হয়নি।
2. `/app`-এ গিয়ে বাংলা নমুনা টেক্সট দিয়ে Generate করুন — অডিও বাজতে
   হবে ও MP3 ডাউনলোড হতে হবে।
3. `/api/voices`-এ `source: "live"` দেখা গেলে লাইভ ভয়েস তালিকা কাজ করছে।

## খরচের হিসাব (প্রাইসিং কেন এমন)

- প্রায় ১,০০০ ক্যারেক্টার = প্রায় ১ মিনিট ভয়েস।
- ElevenLabs API: Turbo/Flash-শ্রেণি $০.০৪ / ১,০০০ ক্যারেক্টার;
  v4-শ্রেণি $০.০৮ / ১,০০০ ক্যারেক্টার।
- তাই দাম খরচের ওপরে মার্জিন রেখে ধরা হয়েছে। `/pricing` পেজের সব দাম
  DRAFT — বিক্রির আগে মালিকের অনুমোদন লাগবে।

## লোকালভাবে চালানো

```bash
npm install
npm run dev
```

তারপর http://localhost:3000 খুলুন। লোকাল টেস্টের জন্য `.env.local`-এ
`ELEVENLABS_API_KEY=...` বসাতে পারেন — এই ফাইলটি `.gitignore`-এ আছে,
তাই ভুলেও GitHub-এ যাবে না।

## গুরুত্বপূর্ণ নিয়ম

- API key শুধু সার্ভারে (`process.env`) থাকে — ফ্রন্টএন্ডে কখনো যায় না।
- ইউজারের টেক্সট সার্ভারে সংরক্ষণ করা হয় না — শুধু ক্যারেক্টার সংখ্যা,
  ভয়েস ও মডেলের হিসাব থাকে।
- অন্য কারো ভয়েস ক্লোন করতে হলে তার লিখিত অনুমতি বাধ্যতামূলক।
- এই টুল ElevenLabs API ব্যবহার করে, কিন্তু ElevenLabs-এর সাথে কোনো
  অফিসিয়াল পার্টনারশিপ দাবি করা হয় না।
